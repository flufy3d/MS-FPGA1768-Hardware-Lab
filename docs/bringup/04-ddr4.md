# 04 — DDR4 bring-up

> Status: reported (prior art), not yet reproduced in this lab

## Goal

Get both DDR4 channels calibrated and run a memory test from the FPGA.

## Reference design

`reference/catapult-v3-smartnic-re/Projects/DDR4/` contains three projects:

| Project | Content |
|---------|---------|
| `DDR4_Top` | one EMIF for the top channel, calibration status on LEDs |
| `DDR4_Bot` | one EMIF for the bottom channel |
| `DDR4_Dual` | both channels, useful as a template for a real design |

Each has a Platform Designer system (`Qsys.qsys`) with:

- Arria 10 EMIF IP, DDR4, 72-bit, 2400 MT/s class,
- PLL reference clock from Y3/Y4 (266.667 MHz),
- `oct_rzqin` connected to the 240 Ω pin,
- calibration status exported to LEDs.

## Steps

1. Copy `DDR4_Dual` into `projects/03_ddr4_dual/`.
2. Open the `.qsys` in Platform Designer, upgrade the IP for Quartus 25.1, regenerate.
3. Compile and program.
4. Watch the calibration LEDs:

| LED | Signal |
|-----|--------|
| `led[0]` | top channel `local_cal_success` |
| `led[1]` | top channel `local_cal_fail` |
| `led[3]` | bottom channel `local_cal_success` |
| `led[4]` | bottom channel `local_cal_fail` |

5. When calibration succeeds, add the EMIF "Example Design" or a traffic generator and run
   a walking-1 / PRBS test over the Avalon-MM interface.

## What success proves

- Both DDR4 channels are populated and wired correctly.
- The reference clocks and OCT calibration resistor are good.
- The EMIF parameters in the reference project match this board.

## If calibration fails

| Symptom | Likely cause |
|---------|--------------|
| Fail immediately | Missing `oct_rzqin`, wrong refclk pin, or EMIF not licensed/regenerated |
| Fail after sweep | Board skew parameters wrong; copy the original `.qip`/settings, do not let Quartus re-generate them from scratch |
| One channel only | That channel's rail or one DRAM device is dead |
| Passes but data errors | Timing margin; reduce frequency to 1600 and retest |

## Notes

- The board has 4.5 GB usable, not 5 GB. Memory tests that walk the full 5 GB will fail at
  the top of each channel.
- ECC is wired; enable it only if you understand the extra 8 bits per channel.
- The Arria 10 EMIF calibration is temperature sensitive; run it cold and hot.
