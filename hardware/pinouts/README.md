## Quick reference

### Clocks

| Signal | Pin | Frequency |
|--------|-----|-----------|
| `clk_u59` | `AP20` | 100 MHz |
| `clk_y3` / `_n` | `AG5` / `AG6` | 266.667 MHz |
| `clk_y4` / `_n` | `J3` / `K3` | 266.667 MHz |
| `clk_y5` / `_n` | `U29` / `U28` | 644.53125 MHz |
| `clk_y6` / `_n` | `E29` / `E28` | 644.53125 MHz (156.25 on OCP) |
| `clk_pcie1` / `_n` | `AN29` / `AN28` | 100 MHz |
| `clk_pcie2` / `_n` | `AE29` / `AE28` | 100 MHz |

### LEDs

`AM17 AH18 AJ18 AH17 AJ16 AK17 AK16 AK18 AL18` → `led[0..8]`, 1.8 V.

### JTAG

Dedicated pins, no user constraint needed. Header J5: 1 TCK, 3 TDO, 5 TMS, 9 TDI, 2/10 GND,
4 VCC 1.8 V.

### I2C

| Bus | SDA | SCL | Devices |
|-----|-----|-----|---------|
| 1 | `L20` | `K20` | 0x22 retimer, 0x50 QSFP |
| 2 | `K21` | `J23` | 0x27 GPIO exp, 0x40 VR, 0x42 hot-swap, 0x4C temp, 0x51 EEPROM, 0x6D clock, 0x1F/0x48 NIC |
| 3 | via U32/J9 | | Mellanox management |

### PCIe

| Interface | PERST# | Lanes |
|-----------|--------|-------|
| #1 | `AW16` | `AN33/AN32 … AH31/AH30` |
| #2 | `AV18` | `AE32/AE33 … Y39/Y38` |

## Caveats

- The upstream spreadsheet marks some rows as "Shared" or leaves the component column
  empty for continuation rows; the CSV export preserves that layout, so a pin without a
  signal name belongs to the row above.
- Pin names are package positions (`AM17`), which Quartus writes as `PIN_AM17`.
- Several signals are marked "Only in OCP version" or "Only in PCIe version" — check the
  `Remarks` column before using them.
- The CSV files are generated by a script (`scripts/export-pinouts.ps1` in a future
  revision); until then they are one-off exports and may not include formatting from Excel.
